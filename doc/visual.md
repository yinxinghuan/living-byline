# Visual Bible

## 1. Visual thesis

- **情绪承诺**：玩家不是把碎片拖回去，而是亲手找到一座空间雕塑隐藏的正确阅读角度。
- **标志性时刻**：48 个厚三角体、球体、拱门与多面体仍相差约 4 个世界单位，但完整编辑版式突然在屏幕中严丝合缝。
- **必须具备**：明确的 3D 景深、每关不同的几何剪影、无拉伸且正向的排版。
- **禁止方向**：平面切片收拢、扫描线、反字、通用霓虹玻璃卡。

## 2. Composition and camera

- 竖屏主验收 `390×844` 与 `320×568`。
- 固定投影机使用 `24°`、`2:3`；可旋转观察相机使用 `34°`，因此完整雕塑能落入窄屏而不改变纹理比例。
- 初始画面必须清楚看见三角断面、侧面厚度、遮挡和前后关系；正确视角中几何不能移动，却必须在视觉上完全消失为一张无缝矩形平面稿。
- 顶部 HUD 从 safe area 下 `18px` 开始；底部对齐仪与完成面板不遮住署名中心。

## 3. Color and type

- 背景 `#07090D`；纸面 `#F3F0E8`；珊瑚 `#FF5B4D`；电蓝 `#4D7CFF`；锁定薄荷 `#A8FFD8`。
- 用户名使用 `Arial Black / PingFang SC` 900 字重；HUD 使用 Inter 与等宽字体。
- 用户名最多 18 个 Unicode 字符，纹理按长度缩放/换行，不替换为固定标题。
- 页面包含顶部刊头与平台期号、红蓝双色 hero、巨大用户名、编辑主标题、栏目编号、双栏内文、三色色卡和页脚索引。
- 投影纹理保持 `1024×1536`，圆环与字形禁止非均匀缩放。

## 4. Shape, material, and lighting

- **共同基础**：48 个三角 ExtrudeGeometry 以 `4×6×2` 镶嵌覆盖投影页；每片按 `(cameraRadius-z)/cameraRadius` 缩放并向质心外扩 3.5%，确保正确视角无发丝缝。
- **拱门庭院**：双拱、三球与锥柱形成建筑残片。
- **折面剧场**：双空间环、圆锥、双球与八面体形成舞台机械。
- **轨道雕塑**：三重圆环、中心轴、双球与二十面体形成轨道机器。
- 错误视角中侧面为暗墨；正确视角中 resolve uniform 把所有可见投影面恢复为页面原色，不留下模型阴影。
- 完成时不删除、不淡出、不共面化任何物体；“平面”只是一种精确观察结果。

## 5. UI and motion

- 顶部仅保留身份与关卡；底部用圆形对齐仪显示 `00–100`，不再使用三点路径。
- 对齐度超过 82% 时仪表变薄荷并轻微呼吸；超过 90% 后提示保持视角。
- 输入同帧改变相机目标，松手后使用轻磁吸；完成面板在锁定后 `380ms` 出现。
- `prefers-reduced-motion` 停止幽灵手与循环呼吸，但保留直接相机响应和状态文字。

## 6. References and adaptation

- 参考 Cullen Webber 的 `three-html-to-canvas`：保留“DOM 排版作为投影纹理、观察视角决定可读性”的核心机制。
- 上游无明确许可证，因此不复制源码、模型、原排版、镜头关键帧或品牌资产；当前 shader、纹理器与程序几何均为独立实现。
- 产品化只增加身份、三关结构、触控相机、对齐判定与反馈，不改变投影错视的本质。

## 7. Acceptance

- 初始视角一眼可见球、拱、多面体、三角断面及至少 `3.2` 世界单位景深。
- 真实单指拖动能改变 yaw 至少 `0.25 rad` 并完成三关。
- 完成时角误差不超过 `0.035 rad`，但场景几何数量、位置和深度保持不变。
- 三关均包含 `SphereGeometry`、`TorusGeometry` 与 48 个 `ExtrudeGeometry`，每关至少 55 个场景对象。
- 两档手机无横向溢出；文字正向、无扫描线、projector aspect 与纹理 aspect 相同。
- 正确视角必须呈现连续 `2:3` 平面设计：无发丝缝、暗边和法线阴影，且能读出 hero、主标题、小标题与正文层级。
