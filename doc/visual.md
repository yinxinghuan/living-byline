# Visual Bible

## 1. Visual thesis

- **游戏与玩家**：AlterU 手机端玩家在 1–3 分钟内旋转观察一座投影雕塑，找到隐藏身份版式的唯一正确角度。
- **情绪承诺**：从复杂空间干扰中突然看见一张安静、精确、像印刷成品一样完整的个人身份稿。
- **一句话方向**：选择 `Open Field`——以 AlterU 矢量水印作为空间主体，用移动轴线、高留白和矿物色系把三关组织成同一出版系列。
- **标志性时刻**：球体、拱门、多面体和远近不均的页面碎片仍横跨超过 5 个世界单位，但在正确视角中突然严丝合缝为连续 `2:3` 平面稿。
- **必须具备**：明确 3D 景深；官方 SVG 水印；不拉伸的动态用户名；无接缝、阴影和扫描线的完成稿。
- **避免方向**：UI 卡片拼贴；高饱和红蓝对撞；头像抠图；通用粗黑字体；等面积切块与等距分层。

## 2. Composition and camera

- 竖屏主验收 `390×844` 与 `320×568`。
- 固定投影机使用 `24°`、`2:3`；观察相机使用 `34°`，yaw 无边界、pitch 为 `[-1.42, 1.42]`。
- 初始画面必须出现三角断面、侧面厚度、遮挡、球体/拱形/多面体和至少 `5` 世界单位景深。
- 完成稿采用五个开放场域和一个移动轴；稳定锚点是左上微型元数据、右上关卡号及大面积留白。
- 顶部 HUD 从 safe area 下 `18px` 开始；底部对齐仪与完成面板不得遮住核心水印或用户名。
- 注意路径：空间剪影 → 破碎水印 → 用户名线索 → 对齐值 → 完整版式。

## 3. Color

- **场景背景**：深矿物黑 `#06110E`。
- **主要场域**：粉笔绿 `#DFE4D7`、矿物绿 `#15392F`、铜色 `#9B553D`。
- **次级强调**：浅铜 `#BB7257`；锁定反馈用鼠尾草绿 `#B9DDC7`。
- **比例**：每关一个主场域约 `65–85%`，第二场域 `15–35%`，强调色不超过 `12%`。
- **禁止**：电蓝、霓虹、红蓝互补、玻璃渐变、发光描边和用阴影掩盖层级。

## 4. Typography

- **身份显示**：`Avenir Next / Helvetica Neue / PingFang SC`，600；禁止 `Arial Black`。
- **元数据与 HUD**：`Avenir Next / Helvetica Neue` 600，等宽字体仅用于对齐数值和印章。
- 用户名最多 18 个 Unicode 字符；通过字号、换行和方向变化适配，绝不做非均匀缩放。
- 仅 `1–12` 个拉丁字母、数字、空格、点号或连字符的名字可使用竖向阅读轴；中文、混合文字和长名字切换为右侧横排块。
- 固定文字全部为英文；用户名保留玩家真实内容，不翻译。

## 5. Shape, material, and lighting

- 页面经过 2–5 层非对称递归分割，形成 `12–36` 个矩形与三角 ExtrudeGeometry；最大/最小面积比至少 `8:1`。
- 约半数块聚集在 `|Z|<0.5`，三个极端锚点跳到 `|Z|>2.4`；禁止正弦波式等距分层。
- 三关分别以双拱庭院、折面剧场和三重轨道雕塑建立不同空间剪影。
- 侧面为深矿物材质，光源使用粉笔白、铜色与低饱和矿物绿。
- 正确视角的 resolve 阶段恢复页面原像素，不保留 mesh 阴影、法线明暗或发丝缝。

## 6. Characters, environments, and assets

- 官方 AlterU 水印直接使用通用 `256×256` SVG 的两条 path，不从图片描摹、不使用默认头像代替 Logo。
- 头像只作为完整矩形 `field`，不抠图、不圆形裁切；保持中心焦点并允许灰度处理。
- `01`：粉笔场域、左侧超大水印、右侧移动名字轴。
- `02`：矿物场域、中部完整头像横带、跨场域水印、底部身份文字。
- `03`：铜色场域、上部大标题式用户名、右下矿物水印块。
- 投影纹理固定 `1024×1536`；图片和字形均保持原始纵横比例。

## 7. UI and icons

- 顶部仅保留身份与关卡；底部圆形对齐仪显示 `00–100`。
- 功能图标统一使用实心 SVG；禁止 Emoji。
- 完成面板为粉笔绿实色矩形、铜色左边界和深矿物按钮，不使用圆角、阴影、玻璃或渐变。
- 交互目标至少 `44×44px`；键盘 focus 使用 `2px` 铜色外框。
- 错误状态使用同一矿物/铜色系统并提供 `48px` 高重试按钮。

## 8. Motion and VFX

- 输入同帧改变相机目标；拖动阻尼为 `0.24`，松手为 `0.14`。
- 对齐超过 `82%` 时仪表以鼠尾草绿呼吸；误差小于 `0.032rad` 并保持 `380ms` 后锁定。
- 完成态不移动、删除或共面化几何；只锁定观察姿态并显示完成 UI。
- `prefers-reduced-motion` 停止幽灵手与循环呼吸，保留直接相机响应和状态变化。
- 不使用粒子、屏幕震动、扫描线或炫光。

## 9. References translated into principles

- **Cullen Webber / three-html-to-canvas**：保留“DOM 排版作为投影纹理、观察视角决定可读性”；不复制上游源码、模型、排版或镜头。
- **Open Field 方向稿**：采用移动轴线、矢量水印主体、高留白和矿物色系；不把静态稿中的具体用户名或画板内容硬编码进游戏。
- **编辑设计系列原则**：三关共享网格家族、字体角色、色彩角色和水印行为，但改变名字方向、头像参与和空间密度。

## 10. Anti-patterns

- 禁止照片 Logo、头像抠图、圆形头像徽章和位图描摹。
- 禁止 `Arial Black`、字体水平/垂直拉伸、反字和栅格化文字。
- 禁止等宽条带、相似面积碎片、等距离景深和全场以板子为主。
- 禁止通用 UI 卡、浮动圆角面板、渐变、阴影、辉光、噪声和扫描线。
- 禁止固定中文演示文案；玩家真实用户名可包含任意语言。

## 11. Vertical-slice acceptance

- **Entry**：错误视角一眼能看出复杂 3D 体积与非均匀景深。
- **Gameplay**：真实单指拖动能连续水平多圈、竖直越过旧限制，并保持响应直接。
- **High-feedback moment**：接近正确角度时水印和名字逐渐连续，对齐仪从白转鼠尾草绿。
- **Completion**：三关分别形成 Open Field 三个系列变体；纹理正向、字体无拉伸、页面无缝且无模型阴影。
- **Narrow mobile**：`320×568` 不横向溢出，长混合用户名不会形成拥挤竖柱。
- **QA 决策**：以 `_qa/ui/open-field-selected-*` 为本轮同状态证据；P0/P1 必须为零。
