# Requirements

## 1. Overview

《Living Byline / 活字世界》是一款 1–3 分钟、竖屏、无失败的三关触屏视觉游戏：玩家在三个 3D 身份投影室中沿套准路径划过三个大节点、恢复破碎排版，最终把自己的 AlterU 用户名与平台名印成可自由观看的立体署名。

玩家是从 AlterU 信息流进入的手机用户。默认产品入口使用当前玩家用户名；平台外以 `AlterU` 回退。`?user_name=` 可用于浏览器调试，`?baseline=1` 仅保留独立实现的技术基线，不显示产品 HUD 与关卡闭环。

## 2. Visual Design

主画面是占据全屏的 3D 投影室，HTML 排版生成的画面纹理跨越多块几何表面，随着视角变化出现断裂、重合和重新对齐。视觉采用深墨背景、纸白文字、荧光珊瑚与电蓝双投影色，不复制参考作品的白色展厅、红色方卡、模型或原排版。

界面分为顶部安静的关卡/署名 HUD、中央完整触控区域、底部隐藏手势提示与关卡完成操作。全部功能图标使用同一套 24×24 单色 SVG 线性图标；不使用 Emoji。目标尺寸为 `390×844` 与 `320×568`，平台内主构图不为外部访客栏预留空间。

三个场景：

1. **Threshold / 门廊**：折线路径横穿竖框和悬浮纸板，玩家恢复名字的第一行。
2. **Fold Theatre / 折页剧场**：V 形路径穿过折页舞台，玩家恢复 `× ALTERU` 平台署名。
3. **Orbit Press / 轨道印刷机**：拱形路径环绕印刷轨道，玩家把两行署名锁成最终雕塑。

## 3. Game Mechanics

- 初始状态：第 1 关、0/3 套准点已激活、相机方位角 `0`、俯仰角 `-0.05`。
- 每关包含一条屏幕空间套准路径与 3 个直径 `68 CSS px` 的节点；窄屏节点直径 `62 CSS px`，另有 `14px` 命中宽容区。
- 玩家可以从当前发光节点开始连续划过整条路径，也可以依次轻触节点；只有当前节点响应，顺序明确。
- 每激活一个节点，DOM 节点同帧压入、声音升高一级、可用设备触发 `12ms` 轻振，并把投影清晰度与场景对齐量增加 `1/3`。
- 第三个节点触发 `18/24/24ms` 分段振动、`520ms` 定型与完成操作；路径淡出后才开放相机拖动，装配输入与观看输入不会竞争。
- 第 1、2 关完成后进入下一关；关卡切换由 `420ms` 淡出、几何重建、`620ms` 淡入组成。
- 第 3 关完成后保留最终雕塑，显示玩家署名、三个关卡印章与“再印一次”。
- 关卡完成后，单指拖动控制相机：水平总范围 `±0.62 rad`，垂直范围 `-0.28–0.24 rad`，阻尼系数 `0.08`。
- 投影纹理由可访问的隐藏 DOM 排版生成，不读取跨域图片像素。
- 运行循环只在页面可见且场景与视口相交时更新；隐藏或可见比例低于 `0.08` 时暂停 RAF。
- `prefers-reduced-motion` 下移除幽灵手循环和大幅过渡，把相机与几何回弹缩短为 `80ms`。

## 4. Controls

- **连续划动**：从当前发光节点出发，沿连线穿过后续节点；一次手势可以完成整关。
- **依次轻触**：不方便连续划动时，可分别轻触当前高亮节点。
- **完成后单指拖动**：环绕观察已套准场景；装配过程中不旋转相机。
- **关卡完成按钮**：第 1、2 关进入下一场景，第 3 关重新开始。
- **键盘**：`Enter` 激活当前节点；关卡完成后方向键旋转相机；`R` 在终局重新开始。
- 入口幽灵手使用 Material `touch_app` 图形，沿第 1 关真实套准路径移动，并同步触发当前节点呼吸与投影扫描，不推进进度。

## 5. Win / Lose Conditions

游戏没有失败和倒计时。每关划过 3 个套准点即完成该关；完成全部 9 个套准点后胜利。

终局显示：

- 玩家用户名；
- `PRINTED WITH ALTERU` / `由 ALTERU 印制`；
- 三个已完成场景印章；
- “再印一次”按钮；
- 保持可拖动的最终 3D 署名雕塑。

纹理或 WebGL 初始化失败时显示可恢复错误界面，包括简短原因、“重试”按钮和纯 DOM 署名卡，不出现空白画布。

## 6. Sound Effects

音频在第一次用户手势后创建，失败时不阻塞游戏。

- 套准点激活：三角波 `520–760Hz`，`120ms`，随本关进度升高，音量 `0.04`。
- 关卡定型：两个正弦音 `330Hz + 495Hz`，`360ms`，`30ms` attack / `300ms` release，音量 `0.045`。
- 终局印刷：低频三角波 `110Hz` 与正弦波 `660Hz` 分两次进入，总长 `620ms`，音量上限 `0.055`。
- 长按增强：带通噪声 `700–1400Hz`，最多 `900ms`，音量上限 `0.018`，松手后 `120ms` 淡出。
