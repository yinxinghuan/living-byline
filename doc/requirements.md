# Requirements

## 1. Overview

《Living Byline / 活字世界》是一款 1–3 分钟、竖屏、无失败的三关 3D 视错觉游戏：玩家旋转观察相机，直到投射在球体、拱门、柱体与折面上的 `用户名 × AlterU` 从碎裂状态拼成完整排版。

默认产品入口使用当前 AlterU 玩家用户名；平台外回退为 `AlterU`。`?user_name=` 用于浏览器调试，`?baseline=1` 仅保留技术基线并隐藏产品 HUD。

## 2. Visual Design

主画面是全屏黑色投影室。HTML 排版纹理由一台不可移动的投影机投向固定 3D 雕塑；玩家观察相机从错误角度看见断裂文字，旋到唯一正确角度后看见完整署名。场景在过关前后始终立体，不把物体收拢为平面。

三关共享一套确定性不规则镶嵌：页面通过 2–5 层非对称递归分割形成 `12–36` 个大小差异明显的矩形/三角承载体；每片按自身 Z 深度做投影透视补偿。最大块与最小块面积比至少 `8:1`。错误视角中它们强烈错位，正确视角中边缘互相覆盖为无缝矩形。

1. **拱门庭院**：最大页面块位于极近层 `Z≈2.95`，第二大块落到 `Z≈-2.68`，叠加双拱、3 颗球体与双锥柱。
2. **折面剧场**：最大/第二大块反转前后关系为 `Z≈-2.85 / 2.72`，叠加双空间环、2 个圆锥、2 颗球体与八面体。
3. **轨道雕塑**：最大块在 `Z≈2.95`，最小强调片跳到 `Z≈-3.05`，叠加三重圆环、中心轴、球体与二十面体。

主验收尺寸为 `390×844` 与 `320×568`；平台内构图不为外部访客栏预留空间。

## 3. Game Mechanics

- 三关目标观察姿态分别为 `(yaw, pitch) = (0.30, -0.035)`、`(-0.34, 0.09)`、`(0.18, 0.16)`。
- 每关从距目标约 `0.70–0.75 rad` 的错误姿态开始。
- 单指拖动按 `yaw -= dx × 0.006`、`pitch += dy × 0.0048` 改变观察相机；几何、投影机与投影纹理不移动。
- 观察相机目标姿态限制在目标 yaw `±1.15 rad`、pitch `[-0.58, 0.58]`。
- 对齐度由观察姿态与目标姿态的二维角误差计算；误差 `0.74 rad` 外为 0，接近目标时平滑升至 1。
- 松手且误差小于 `0.13 rad` 时启用轻微磁吸；误差小于 `0.032 rad` 并持续 `380ms` 后过关。
- 第 1、2 关完成后进入下一场景；第 3 关完成后可重新开始。
- 投影纹理固定为 `1024×1536`；投影相机固定 `24° / 2:3`，观察相机使用 `34°` 并跟随手机 viewport，禁止非均匀拉伸字体。
- CanvasTexture 不二次翻转 Y；文字只投到朝向投影机的表面；不使用扫描线。
- 对齐度超过 `0.72` 后逐步解除正面明暗遮罩；精确视角中，三角体、球体和圆环共同采样同一页面像素，视觉上消除接缝、侧面与阴影，但 mesh transform 保持不变。
- 至少 25% 且不超过 75% 的页面块聚集在 `|Z|<0.5` 的中性深度；其余分布到中距层，并保留 3 个 `|Z|>2.4` 的极端前后锚点，禁止等距波浪。
- 最终版式包含双色主视觉块、期号、用户名主标题、平台署名、编辑主标题、栏目小标题、双栏内文、色卡与页脚索引。
- 页面隐藏或场景可见比例低于 `0.08` 时暂停 RAF。

## 4. Controls

- **单指拖动**：旋转观察相机，寻找文字连续的唯一视角。
- **松手微调**：进入目标附近后由磁吸辅助精确锁定。
- **方向键**：以 `0.035 rad` 步长微调；按住 Shift 时使用 `0.08 rad`。
- **完成按钮**：进入下一关；终局重新开始。
- 入口幽灵手仅演示真实的横向旋转，不推进进度。

## 5. Win / Lose Conditions

游戏没有失败、倒计时或生命值。每关在观察姿态误差小于 `0.032 rad` 并维持 `380ms` 后胜利。完成态保留同一座 3D 雕塑和正确观察视角，显示玩家署名、关卡印章与下一步按钮。

WebGL 或纹理初始化失败时显示纯 DOM 恢复界面与 48px 高“重试”按钮，不出现空白画布。

## 6. Sound Effects

- 首次进入高对齐区：三角波 `520–760Hz`、`120ms`、音量 `0.04`，并触发 `10ms` 轻振。
- 关卡锁定：正弦波 `330Hz + 495Hz`、约 `360ms`，配合 `18/28/24ms` 分段振动。
- 终局锁定：三角波 `110Hz` 与正弦波 `440/660Hz`，总长约 `620ms`。
- 音频在首次用户输入后创建；不可用时静默降级，不阻塞过关。
