# Living Byline

An original AlterU mobile visual game about restoring a player's identity across three projected typographic spaces.

## Concept reference and license boundary

The project began from observing Cullen Webber's public
[`three-html-to-canvas`](https://cullenwebber.github.io/three-html-to-canvas/)
demo and reading repository revision
[`bad1a7c7`](https://github.com/cullenwebber/three-html-to-canvas/commit/bad1a7c78c5b8761c95b9c4cbfcfed7f48c2d44d).
That repository did not include a software or asset license when this project
was created. No upstream source code, `model.glb`, layout, logo, copy, or other
asset is distributed here. Living Byline independently implements the general
browser technique with original TypeScript, shaders, procedural geometry,
composition, interaction, and game structure.

Third-party software actually distributed with this project is listed in
`public/THIRD_PARTY_NOTICES.txt`.
